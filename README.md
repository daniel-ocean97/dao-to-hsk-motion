# Dao to HSK — Motion

Анимационные ролики для курса китайского языка **Dao to HSK**: интро к урокам,
позже промо. Главная героиня — стилизованный образ Риты, преподавателя курса.
Стиль — между тушью и акварелью, приглушённые цвета, палитра бренда «Тушь».

Сайт курса живёт в отдельном репозитории `dao-to-hsk`.

## Ролики

| Ролик | Статус | План |
|---|---|---|
| `intro-01` — интро к урокам, 26,4 с, 16:9 | MP4 просмотрен | [docs/intro-01-plan.md](docs/intro-01-plan.md) · [раскадровка](docs/intro-01-storyboard.md) |

## Как устроено

Ролик — это HTML-страница с SVG и Canvas, где всё нарисовано кодом, и одна
функция `renderAt(t)`: она рисует кадр для момента времени `t`. Скрипт на
Python открывает страницу в невидимом браузере, снимает каждый кадр по
времени `i / 60` и склеивает кадры с музыкой в MP4 через FFmpeg.

Так ролик воспроизводим: тот же код всегда даёт тот же файл, и любую сцену
можно поправить, не перерисовывая остальные.

Готовый ролик: MP4, 1920×1080, 60 fps, H.264, звук AAC.

## Структура

```
docs/                план роликов, персонаж, бренд, история проекта
characters/rita/     персонаж: SVG по слоям (появится на этапе пробы)
videos/<ролик>/      сцены и таймлайн конкретного ролика
shared/              общий код: таймлайн, фильтры туши и акварели
render/              скрипт покадрового рендера и сборки MP4
music/               музыка и звуки с указанием лицензии
out/                 кадры и готовые MP4 (в git не попадают)
.agents/skills/      Codex skills: vizavi-motion и explain
.codex/agents/       Codex subagent: chinese-checker
```

## Первоначальная настройка

Установи [uv](https://docs.astral.sh/uv/) и FFmpeg. Затем из корня проекта:

```bash
uv sync                            # Python и библиотека Playwright
uv run playwright install chromium # браузер для покадрового рендера
```

Chromium устанавливается отдельно: `uv sync` ставит только Python-зависимости,
а браузер является отдельной программой. Эти две команды нужны один раз на новом
компьютере или после обновления версии Playwright.

Проверка рендера без звука:

```bash
uv run render/render.py videos/intro-01/index.html
```

Готовый файл появится в `out/intro-01/intro-01.mp4`. Чтобы добавить музыку:

```bash
uv run render/render.py videos/intro-01/index.html --audio music/local/track.mp3
```

Подставь реальное имя аудиофайла. Необязательные параметры: `--audio-start N`
начинает трек с N-й секунды, `--audio-fade N` плавно затихает звук за последние
N секунд ролика. Для проверки отдельных моментов без полного рендера:

```bash
uv run render/render.py videos/intro-01/index.html --stills 18.0 22.4 24.3
```

## Как посмотреть сцену

Сцены открываем через локальный сервер, а не двойным щелчком по файлу:
браузер не даёт коду читать пиксели картинок, открытых как файл, а механизму
анимации Риты (`shared/rig.js`) это нужно.

```bash
uv run python -m http.server 8000
# открыть http://localhost:8000/videos/probe-rig/
```

Проба механизма анимации на временной картинке:

```bash
uv run render/placeholders.py                     # временные картинки Риты -> out/rita-placeholder/
uv run render/render.py videos/probe-rig/index.html   # MP4 -> out/probe-rig/
```

`?debug` в адресе показывает сетку и области: красное гнётся ветром, синее
подменяется (`?debug=turn` — голова при повороте, `?debug=blink` — глаза).

## Инструменты

- Python 3.13 и [uv](https://docs.astral.sh/uv/) — скрипт рендера
- Playwright (Chromium) — невидимый браузер для покадровой съёмки
- FFmpeg — сборка кадров и звука в MP4

Команды запуска появятся вместе со скриптом рендера.
