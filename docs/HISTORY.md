
## Ключевые решения

| Тема | Решение | Почему |
|---|---|---|
| Репозиторий | Отдельный приватный `dao-to-hsk-motion` | Ролики не связаны с кодом сайта; работа с любого устройства |
| Аватар | Рисуем кодом (SVG/Canvas) в стиле туши и акварели; сначала проба | Персонаж одинаковый во всех роликах и анимируется кодом; внешний сервис — запасной путь |
| Речь | В интро нет, губы не анимируем | Задумка владельца: красивые кадры под музыку и текст |
| Методика | Скилл `vizavi-motion` v1.6.1 | Раскадровка с вариантами, обязательная итерация, проверка готового MP4 |
| Техника | HTML + SVG/Canvas, функция `renderAt(t)`, рендер Python + Playwright, сборка FFmpeg | Без Node.js; кадры воспроизводимы |
| Личные данные | Фото Риты не коммитим и не загружаем во внешние сервисы без её согласия | Это личные данные; на одном фото ребёнок |
| Музыка | Бесплатная с лицензией для YouTube и коммерции, учёт в `music/CREDITS.md` | Своей музыки пока нет |

## Журнал

### 2026-10-26 — Проба Риты (этап 2, черновик)

**Сделано:** установлены FFmpeg (winget) и Playwright + Chromium (uv,
`pyproject.toml`). Общий код: `shared/timeline.js` (время, кривые бренда из
`tokens.css`), `shared/ink.js` (фильтры туши, камера с параллаксом, пейзаж).
Рита по слоям — `characters/rita/rita.js`: поза A (полупрофиль) и поза B
(спиной, поворот головы), волосы — пряди с волной от корней к кончикам.
Сцена пробы `videos/probe-rita/` (6,5 с) и рендер `render/render.py`.
Проверено: `ffprobe` — 1920×1080, 60 fps, H.264, yuv420p, 6,5 с, без звука;
кадры на стыках частей просмотрены. В движении владельцем — ещё нет.
**Решения:** звук в пробе не делаем — музыка на этапе 3. Части пробы склеены
встык: это проверка трёх рисков, а не сцена ролика.
**Проблемы:** профиль в позе B закрывали пряди → профиль рисуется поверх
волос, щёку закрывает прядь у виска, сверху — макушка. Волосы в порыве
задирались флагом, пряди у виска торчали спицами → ослаблен отклик на порыв.
Мазки выглядели палками → «сухая кисть» из трёх волосков, хвост стартует
у кончика пряди.
**Уроки:** механика работает (ветер, слои, поворот, мазки, рендер ~0,7 с на
кадр). Слабое место — художественное качество персонажа: фигура жёсткая,
стиль ближе к вектору, чем к туши с акварелью; масса волос плотная. Это
поднимать до сборки ролика. На новом компьютере: `uv sync`,
`uv run playwright install chromium`, установить FFmpeg; рендер —
`uv run render/render.py videos/probe-rita/index.html`.

### 2026-10-26 — Раскадровка intro-01 (черновик)

**Сделано:** `docs/intro-01-storyboard.md` — 7 сцен, по 3–5 вариантов и карточка
плана на каждую; эскизы финала A/B/C в `videos/intro-01/storyboard/finale-sketches.html`.
Китайский текст проверен `chinese-checker`: ошибок нет.
**Решения:** нить «ветер — это кисть»: мазки с волос Риты дописывают мир и в
финале пишут 道. Финал — Рита спиной к зрителю (солнце в кадре, нет риска лица,
урок потом начинается с настоящей Риты); поворот через плечо — запасной.
Вторая локация — Гуйлинь (Храм Неба — запасной).
Правки владельца: финал C — спиной, затем поворот головы через плечо после 道
(A — запасной); подписи мест оставляем; финальный кадр держится 2 с, ролик
стал 20 с. В пробу этапа 2 добавлен поворот головы.
**Уроки:** вариант «лицом к зрителю» конфликтует со светом: либо солнце за
камерой и восхода нет, либо лицо в тени. Эскизы с SVG-фильтрами рендерятся
в браузере медленно (секунды) — учесть при рендере кадров.

### 2026-10-26 — Старт проекта

**Сделано:** папка и приватный репозиторий, `README.md`, `CLAUDE.md`, описание
персонажа, бренд для роликов, план первого ролика `intro-01`; скилл
`vizavi-motion` и агент `chinese-checker` в `.claude/`.
**Решения:** сравнили способы получить аватар (рисовать кодом, иллюстратор,
генераторы картинок, сервисы «говорящих аватаров», 2D-риг в программах).
Выбрали код: персонаж стабилен и анимируется, а без речи нужны всего две позы.
Платье — льняное цвета бумаги с вышивкой-лозой и винным поясом; татуировки не рисуем.
**Уроки:** скилл `vizavi-motion` — только инструкции (Markdown), без скриптов;
для его конвейера нужны FFmpeg и headless-браузер, Node.js не обязателен.
