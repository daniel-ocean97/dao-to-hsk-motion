# Бренд «Тушь» для роликов

Источник: `static/css/tokens.css` в репозитории `dao-to-hsk`. Если там что-то
поменяется — обнови этот файл.

## Палитра

| Токен | Цвет | Роль в роликах |
|---|---|---|
| `paper` | `#f5f2ec` | бумага: фон, небо, туман |
| `paper-2` | `#ece6dc` | тёплая тень бумаги, дальние планы |
| `ink` | `#141414` | тушь: контуры, ближние силуэты |
| `ink-2` | `#3e3a36` | разбавленная тушь: средние планы |
| `ink-muted` | `#6b6660` | дальние горы, дымка |
| `line` | `#d6d0c6` | самые дальние слои, следы кисти |
| `wine` | `#7b1e2b` | акцент: пояс Риты, печать, солнце на рассвете |
| `wine-strong` | `#5e1520` | глубокая тень акцента |
| `wine-soft` | `#f3e3e5` | розовая дымка рассвета |

Акварельные оттенки сверх палитры — приглушённые и редкие: охра (шляпы,
черепица, рассвет), серо-голубой (вода, небо), выцветший зелёный (сосны).
Яркие насыщенные цвета не используем.

## Шрифты

| Роль | Шрифт |
|---|---|
| Заголовки, «Dao to HSK» | Cormorant Garamond |
| Подписи, служебный текст | Onest |
| Иероглифы | Noto Serif SC |

Все три — Google Fonts под лицензией SIL Open Font License: можно
использовать в видео. Для рендера файлы шрифтов подключаем локально, чтобы
кадр не зависел от интернета.

## Правила

- Любой иероглиф в кадре — с пиньинем.
- Мотивы бренда: иероглиф 道 (dào — «путь»), инь-ян, кисть и печать.
- Движение «оседает, как тушь на бумаге»: плавное торможение в конце, без
  резких пружин. Кривые из `tokens.css`: `ease-out`, `ease-draw`, `ease-stamp`.
