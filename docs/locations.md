# Библиотека локаций

Ролик-интро — это конструктор: структура, музыка, пролог и финал постоянные,
а три места маршрута выбираются из библиотеки `locations/`. Одно место — один
файл, и любое место можно поставить в любой подходящий слот.

## Слоты маршрута: день → закат → ночь

По задумке за ролик проходят сутки: днём мы видим первое место, к вечеру
второе, ночью город, на рассвете возвращаемся к озеру и Рите.

| Слот | Время ролика | Длина | Время суток | Какое место подходит |
|---|---|---|---|---|
| 1 | 5,0–9,5 с | 4,5 с | день | `time: 'day'` |
| 2 | 9,5–12,5 с | 3,0 с | день, в конце ночь накрывает небо | `time: 'day'` |
| 3 | 12,5–15,5 с | 3,0 с | ночь, к концу небо бледнеет к рассвету | `time: 'night'` |

**Слот 3 всегда ночной.** Чаще всего это ночной город (Шанхай, Гонконг, Чунцин,
Гуанчжоу…), но подойдёт и ночной пейзаж, если в нём есть огни: из этих огней
в финале вылетают светлые ленты, которые летят к Рите (`videos/intro-01/scenes/dawn.js`).
Примеры: фонари над рекой, освещённая пагода, огни древнего города.

Каждое место анимировано на 2,5 с, а движок растягивает анимацию под длину
слота. Поэтому одно и то же место подходит и для слота 1, и для слота 2.

## Паспорт локации

Файл `locations/<id>.js` регистрирует место через `DH.location.define(id, {...})`:

| Поле | Что это |
|---|---|
| `name` | название по-русски, для каталога |
| `time` | `'day'` или `'night'`: в какой слот можно ставить |
| `horizon` | y кадра, где стоит подножие гребня (у реки — линия воды) |
| `hasWater` | только у дневных: есть ли вода под горизонтом. Без воды при наступлении ночи место целиком уходит в тушь |
| `night` | только у ночных: `sky` (два цвета ночного неба), `water` (цвет воды или земли), `bank` (y, где начинается вода), `lights` (4 точки ярких огней в конце сцены: из них в финале вылетают ленты к Рите) |
| `caption` | подпись: иероглифы, пиньинь с тонами, позиция, глубина `p` (обязательно с пиньинем, проверка `chinese-checker`) |
| `camera(t)` | камера на время анимации `t` (0–2,5 с): `{ x, y, zoom }`. Обычно `DH.location.glide(от, до)` |
| `setup(k)` | рисует слои через набор инструментов `k` и возвращает `{ frame(t), ridge }` |

`ridge` — главная линия гребня (горы, стена, крыши небоскрёбов). По ней
строятся переходы: силуэт одного места перетекает в силуэт следующего.

Набор `k` (из `shared/location.js`): `begin(имя, глубина)` начинает слой;
`show`, `place`, `view`, `masked` рисуют слои с учётом камеры и параллакса;
`sky`, `mist`, `range` — небо, полоса тумана, горная гряда; `caption(cam, t)`
рисует подпись; `skylineOf(слой)` находит силуэт по нарисованному.

## Как добавить место

Полная процедура — скилл `location` (`.claude/skills/location/`): справка,
лист эскизов (`render/sketch_sheet.py`), проба риска, место целиком, проверка в
маршрутах и приёмка. Коротко:

1. Раскадровка по скиллу `vizavi-motion`: 3–5 вариантов, выбор, проба риска.
2. Скопировать похожее место (`wall.js`, `guilin.js` для дня, `shanghai.js` для ночи)
   в `locations/<id>.js`, поменять `id`, `name`, `time`, `caption`, паспорт и рисование.
3. Вписать `id` в список `locations/list.js`. Больше ничего подключать не нужно:
   ролик, проба и каталог загружают файлы мест сами.
4. Если в подписи новые иероглифы — `uv run render/subset_fonts.py` (добавит их
   в шрифт `fonts/NotoSerifSC-subset.ttf`) и закоммитить новый шрифт.
5. Посмотреть место: `videos/probe-places/?place=<id>` и в каталоге.
6. Проверить подпись агентом `chinese-checker`.
7. Добавить строку в таблицу ниже.

## Каталог и сборка

Страницы открываются через локальный сервер: в приложении Claude — сервер
`motion` (локальный `.claude/launch.json`, не в git), в терминале — `uv run python -m http.server 8000`.

- **Каталог:** http://localhost:8000/videos/catalog/ — все места с картинками,
  выбор маршрута по слотам (в списках только подходящие места), кнопки «Открыть
  ролик», «Стык 1→2», «Стык 2→3» и готовая команда сборки.
- **Ролик с маршрутом:** http://localhost:8000/videos/intro-01/?route=guilin,wall,shanghai
  (без `route` — `wall,guilin,shanghai`; `&t=9.2` открывает на этой секунде).
- **Сборка одной командой** (около 10 минут):

```bash
uv run render/build_intro.py --route guilin,wall,shanghai
```

  Делает звук (один раз, общий для всех маршрутов), кадры, MP4, проверку
  `ffprobe` и лист стыков `out/route-<ids>/seams.png` — 12 кадров вокруг всех
  переходов. Быстрая проверка без MP4 (около 30 секунд):

```bash
uv run render/build_intro.py --route guilin,wall,shanghai --seams-only
```

Страница ролика проверяет маршрут и пишет ошибку прямо в кадре: если мест
не три, если места нет в `locations/`, если ночное место стоит в дневном
слоте (или наоборот).

## Переходы

Переходы общие для любых мест:

- пролог → слот 1: лист бумаги проходит через кадр;
- слот 1 → слот 2: поднимается туман, гребень первого места тушью перетекает
  в гребень второго (по `ridge` обоих);
- слот 2 → слот 3: ночь (`night.sky`) заливает небо, гребень темнеет,
  вытягивается и становится силуэтом ночного места;
- слот 3 → финал: камера разворачивается к озеру, огни `night.lights` летят к Рите.

Место в слоте 2 идёт 3 секунды, а в слоте 1 — 4,5: анимация растягивается.
