# Чек-лист места перед приёмкой

Отмечай каждый пункт честным статусом; непроверенное так и называй.

## Паспорт

- [ ] `name`, `time` (`day` или `night`), `caption` с пиньинем, `camera`.
- [ ] `horizon` совпадает с подножием главного силуэта в кадре.
- [ ] День: `hasWater` верен (есть ли вода под горизонтом).
- [ ] Ночь: `night.sky` — цвета нарисованного неба; `night.water` и
      `night.bank` — вода или земля под берегом; `night.lights` — 4 точки,
      где в конце сцены (≈2,2 с анимации) действительно горят огни.
- [ ] `ridge` идёт через весь кадр (переход тушью не обрывается).
- [ ] `id` вписан в `locations/list.js`, строка — в таблице docs/locations.md.

## Кадр

- [ ] Видно в кадрах 0,2 / 1,2 / 2,4 с: три плана, параллакс, нет краёв слоёв.
- [ ] Узнаваемые признаки из справки на месте; сомнительные — отмечены для
      владельца.
- [ ] Цвета из палитры и рядом (docs/brand.md), без ярких.
- [ ] Время кадра: `renderAt` меньше ~0,3 с (замер в браузере).
- [ ] Кадр одинаков с чистого листа и после других кадров.

## Подпись

- [ ] Иероглифы и пиньинь проверены агентом `chinese-checker`.
- [ ] `uv run render/subset_fonts.py`, если иероглифы новые; в кадре — тот самый
      шрифт (не запасной).
- [ ] Подпись читается, не лежит на главном объекте, уходит по ветру к концу.

## Маршруты

- [ ] Лист стыков (`build_intro.py --seams-only`) с каждым подходящим соседом:
      день — в слоте 1 и в слоте 2; ночь — после каждого дневного места.
- [ ] Туман 1→2: силуэты перетекают без рывка и провалов.
- [ ] Ночь 2→3: нет полос и «вклеенной» воды; силуэт становится этим местом.
- [ ] Финал: ленты света вылетают из огней места (для ночного).
- [ ] Маршрут по умолчанию (`wall,guilin,shanghai`) не изменился.

## Приёмка

- [ ] Полный MP4 с новым местом, `ffprobe` без замечаний (`build_intro.py`).
- [ ] Просмотрен в движении: начало, конец, стыки.
- [ ] Владелец посмотрел и одобрил.
- [ ] Запись в docs/HISTORY.md, коммит в ветке.
