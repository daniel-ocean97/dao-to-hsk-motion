# Акварель кодом: приёмы и грабли

Всё ниже уже встречалось в проекте (docs/HISTORY.md). Формат грабель:
**симптом → причина → решение**.

## Инструменты

`shared/watercolor.js` (`DH.wc`, в месте — `k.W`):

| Функция | Для чего |
|---|---|
| `wash(ctx, poly, color, {layers, alpha, rough, seed})` | акварельная заливка: десятки полупрозрачных слоёв с рваным краем. Третье число точки — рваность края в ней |
| `ridge({x0, x1, base, peaks, jag, seed, step})`, `peakRow(...)` | линия хребта: пики горной живописи (крутые, скруглённые) + шум |
| `mountains({w, h, ox, oy, ridge, color, deep, fadeTo, ink, inkColor, seed, under})` | горная гряда на своём холсте: подложка, заливки, уход в туман, тушь по гребню |
| `mistBand({w, h, color, seed})` | полоса тумана шире кадра (может плыть и повторяться) |
| `dryStroke(ctx, pts, width, color, {alpha, hairs, dry, seed})`, `taper(pts, w)` | живая тушевая линия сухой кистью; контур мазка переменной толщины |
| `granulate`, `blooms`, `fadeDown` | зерно пигмента, «цветки» высохшей воды, растворение заливки вниз |
| `rng(seed)`, `noise1`, `fbm` | случайность только с зерном (seed) |

`shared/details.js` (`k.D`): `flock`/`birds` — птицы, `ring`/`rings` — круги на
воде, `pine` — сосна, `bamboo` — размытая ветка у объектива, `reeds` — камыш.

Набор места `k` (shared/location.js): `begin(имя, глубина)` — новый слой;
`show`, `place`, `view`, `masked` — нарисовать слой камерой с параллаксом;
`sky`, `mist`, `range`; `densify(poly)` — дробит длинные стороны; `caption(cam, t)`;
`skylineOf(слой)` — силуэт по краске.

## Композиция места

- **Три плана минимум** (дальний 0,2, средний 0,5, ближний 1) и туман между
  ними: параллакс при движении камеры — это и есть «живая камера».
- Высокое и бледное — назад, низкое и тёмное — вперёд. «Пики-великаны»
  впереди низких холмов читаются неправильно.
- Много белой бумаги: светлая сторона остаётся бумагой, заливка — в тени.
- Главный силуэт (`ridge`) — на среднем плане и через весь кадр: по нему
  идут переходы. Если силуэт рваный (город), `skylineOf` найдёт его сам.
- Подпись — в небе или над водой, на своей глубине `p`, не на главном объекте.
- Движения: одно-два тихих в сцене (туман, лодка, птицы, огни). Пестроту
  не добавлять: только цвета палитры (docs/brand.md), малый контраст.

## Грабли

- **Бледный ореол / «гора» в небе у длинной стороны** → `wash()` рвёт край
  пропорционально длине стороны → длинные стороны дробить `k.densify(poly, 14)`.
- **Солнце или небо просвечивает сквозь горы** → у заливки нет подложки →
  `mountains({ under })` или непрозрачная заливка под акварелью.
- **Объект «наклеен»: ровный срез, полоса под ним** → низ растворять вдоль
  склона (`destination-out` с размытым краем), ставить объект за гребень.
- **Линия через всё небо** → `deform()` замыкает контур, обводка хребта
  вернулась к началу → обводить открытую линию, лишние точки срезать.
- **Огни задних домов светят сквозь передние** → перед отрисовкой переднего
  стирать его форму из слоёв огней (`hideLights` в `shanghai.js`).
- **Край нижнего слоя виден при движении камеры** → слои на разной глубине
  расходятся → край прятать под верхний слой с запасом; проверять первый и
  последний кадр сцены.
- **Ровная тёмная заливка читается вырезанной бумагой** → переход тона
  (градиент от гребня вниз) и мягкий тушевой край.
- **Проявление рывком в первые 0,5 с** → ровный темп `ease.draw`, а не `out`.
- **Мелкие детали выходят «антеннами», «чертополохом»** (сосны на хребте) →
  2 варианта на выбор картинками; гуще и мягче, а не тоньше.
- **Подпись другим шрифтом** → canvas молча берёт запасной шрифт → кадры
  ждут `DH.caption.ready` (движок делает это сам). Новые иероглифы — только
  после `uv run render/subset_fonts.py`.
- **Кадр медленный (секунды)** → `filter` (blur) на каждом `drawImage` дорог
  → размывать один раз при рисовании слоя, а не в кадре; мерить `renderAt`.
- **Кадр зависит от порядка** → накопления между кадрами, `Math.random()`
  → всё из `t` и seed; каждый холст кадра очищать.

## Узнаваемость

Узнаваемость — в 2–4 признаках силуэта, не в мелочах. Супердетализация не
нужна (решение владельца), но обязательные признаки должны быть верны: число
ярусов пагоды, форма крыши, порядок главных зданий. Если не уверен — отметь
«проверить по фото» и спроси владельца.
