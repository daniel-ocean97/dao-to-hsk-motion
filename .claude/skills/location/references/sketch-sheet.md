# Лист эскизов

Владелец выбирает по картинкам, поэтому варианты композиции рисуем, а не
описываем.

## Как устроить черновой файл

Черновое место — обычный файл `locations/<id>.js` со всеми полями паспорта.
В `locations/list.js` его **не вписываем**, пока место не принято: каталог его
не покажет, а проба открывает и так (`?place=<id>`).

Внутри `setup(k)` вариант выбирает `k.variant` (строка из адреса или `null`):

```js
setup(k) {
  const V = k.variant || '1';
  if (V === '1') paintCloudSea();      // пики над морем облаков, камера вдоль
  else if (V === '2') paintPineCliff(); // сосна на скале крупно, пики вдали
  ...
  return { frame: FRAMES[V], ridge: RIDGE };
}
```

Эскиз — быстрый: несколько `wash` и `mountains`, грубые формы, без мелких
деталей и без шлифовки. Важно, чтобы были видны три плана, главный силуэт,
место подписи и что будет двигаться (можно стрелкой или вторым кадром).
Подпись ставь сразу: она меняет композицию. Камеру можно оставить простой.

## Как снять лист

```bash
uv run render/sketch_sheet.py --place <id> --variants 1 2 3 4
```

Получится `out/sketch-<id>/sheet.png`: кадр 1,2 с каждого варианта, по три в
ряд, с подписями «вариант N». Чтобы показать движение, добавь моменты — тогда
каждый вариант займёт строку:

```bash
uv run render/sketch_sheet.py --place <id> --variants 2 3 --times 0.2 1.2 2.4
```

## Что показать владельцу

Лист и по строке на вариант: что на трёх планах, что движется, где подпись,
какой силуэт уйдёт в переходы. Отдельно — свой выбор и короткая причина.
После выбора эскизные варианты удаляются из файла, место дорисовывается
начисто (этап 4 скилла).
