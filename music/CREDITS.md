использование (`AGENTS.md`). На каждый файл — строка в таблице.

не попадает в git. Здесь тогда остаётся ссылка, чтобы скачать трек заново.

## Как подобрать трек к ролику

```bash
# где начать трек, чтобы акценты легли на порыв (3,0 с) и первый штрих 道 (16,0 с)
uv run render/music_cues.py music/local/track.mp3
# собрать MP4 из уже отрендеренных кадров с треком: начало, затухание в конце
uv run render/render.py videos/intro-01/index.html --reuse-frames \
    --audio music/local/track.mp3 --audio-start 7.5 --audio-fade 1.5
```
