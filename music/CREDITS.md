# Музыка и звуки

Только бесплатные материалы с лицензией, которая разрешает YouTube и коммерческое
использование (`CLAUDE.md`). На каждый файл — строка в таблице.

Файлы, которые лицензия не разрешает распространять отдельно (например, Pixabay:
«не как самостоятельный файл»), лежат только локально в `music/local/` — эта папка
не попадает в git. Здесь тогда остаётся ссылка, чтобы скачать трек заново.

| Файл | Название | Автор | Ссылка | Лицензия | Content ID | Дата |
|---|---|---|---|---|---|---|
| `music/local/by-the-quiet-water-30s.mp3` (не в git) | By The Quiet Water (30 sec edit) | kaazoom | Pixabay, трек № 383314 — уточнить ссылку на страницу | Pixabay Content License: коммерция и YouTube без указания автора; не распространять отдельным файлом | уточнить (значок-щит на странице) | 2026-10-28 |
| ветер, шелест лепестков | синтез из шума (`render/sound.py`) | — | — | наш звук | нет | 2026-10-28 |

intro-01: трек с 10,2 с (`music_cues.py`: главный акцент на 16,0 с — появление 道,
собственная концовка трека совпадает с концом видео), вход за 1 с.

## Как подобрать трек к ролику

```bash
# где начать трек, чтобы акценты легли на порыв (3,0 с) и первый штрих 道 (16,0 с)
uv run render/music_cues.py music/local/track.mp3
# собрать MP4 из уже отрендеренных кадров с треком: начало, затухание в конце
uv run render/render.py videos/intro-01/index.html --reuse-frames \
    --audio music/local/track.mp3 --audio-start 7.5 --audio-fade 1.5
```
